# ACLCrossAttentionNet

Official implementation of ACLCrossAttentionNet, a deep learning framework for Anterior Cruciate Ligament (ACL) injury detection using knee MRI images.

## Dataset

This study uses the publicly available MRNet-v1.0 dataset.

Dataset access:
https://stanfordmlgroup.github.io/competitions/mrnet/

The dataset is not included in this repository. Users must obtain access to the dataset independently according to its access requirements.

## Requirements

- Python
- PyTorch
- NumPy
- Pandas
- Scikit-learn
- Matplotlib
- OpenCV

## Implementation

The proposed ACLCrossAttentionNet model is implemented in the Jupyter Notebook:

`ACLCrossAttentionNet.ipynb`

## Usage

1. Obtain access to the MRNet-v1.0 dataset.
2. Install the required Python packages.
3. Configure the dataset paths in the notebook.
4. Run the notebook cells sequentially to reproduce the experiments.
